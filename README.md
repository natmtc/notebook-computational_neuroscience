# Computational Neuroscience — Lecture Notes

This repository contains **lecture notes** developed for teaching and learning in **Computational Neuroscience** at Imperial College London.  
The material was created in the context of courses for which I serve as a **Teaching Assistant in Computational Neuroscience**, and reflects my own explanations, and pedagogical approach.

## Status of the repository

This repository is a **living document**.  
The lecture notes will be **continuously updated, revised, and expanded** as the course evolves.

Because of this, content may change between versions.

## Usage and citation

You are welcome to **read and use these lecture notes for personal study and educational purposes**.
